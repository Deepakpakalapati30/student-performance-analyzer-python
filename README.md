# Student Performance Analyzer

A beginner-friendly Python project that analyzes a student's marks and generates basic performance statistics.

## 📌 Features

- Accepts student name and five marks as input
- Calculates total marks
- Calculates average marks
- Finds the highest mark
- Counts marks greater than or equal to 40
- Assigns a grade based on average marks
- Handles invalid input using exception handling
- Uses a `finally` block to indicate completion

## 🛠️ Technologies Used

- Python

## 📚 Python Concepts Used

- Variables
- User input
- Lists
- `map()` and `split()`
- Built-in functions: `sum()`, `max()`
- Loops
- Conditional statements
- Exception handling
- `try`, `except`, `finally`
